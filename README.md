# Statische-Website 
Deze repository bevat een statische website die is gemaakt in de eerste periode van mijn opleiding.
De opdracht was om een website te ontwikkelen over de gemeente waarin ik woon, namelijk Cuijk.
De website bestaat voornamelijk uit HTML en CSS, met ook enkele kleine stukjes JavaScript, zoals de dark/light-modus.
Daarnaast bevat dit project commentaar in de code, omdat dit een van de verplichte onderdelen van het project was.
