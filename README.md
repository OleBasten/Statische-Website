# Statische Website – Leerjaar 1

Deze repository bevat een statische website die ik heb gemaakt tijdens de eerste periode van leerjaar 1 van de opleiding **MBO 4 aan het Koning Willem I College**.  

## Projectstructuur

- `index.html` – De hoofdpagina van de website.  
- `styles/` – CSS-bestanden voor de opmaak van de website.  
- `scripts/` – JavaScript-bestanden voor interactieve functies.  
- `images/` – Alle afbeeldingen die op de website worden gebruikt.  
- `pages/` – Eventuele extra pagina’s van de website.  
- `.vscode/` – Configuratiebestanden van Visual Studio Code (optioneel).  

## Beschrijving

Deze website laat zien hoe een eenvoudige statische website is opgebouwd, met gescheiden mappen voor styling, scripts en media. Het project is gemaakt om te leren hoe HTML, CSS en JavaScript samenwerken en hoe je een overzichtelijke projectstructuur aanhoudt.
